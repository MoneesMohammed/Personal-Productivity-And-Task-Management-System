# Personal Productivity And Task Management System (PPTMS)

A desktop application designed to help users manage their **tasks**, **habits**, and **personal productivity** efficiently.  
Built with **C# WinForms** and **SQL Server**, focusing on clean architecture and a user-friendly experience.

---

## 🚀 Features

### ✅ Task Management
- Create, edit, archive, and complete tasks
- Task priorities (Low, Medium, High, Critical)
- Task status tracking (In Progress, On Hold, Completed, Archived)
- Estimated time for each task
- Task reminders with system notifications
- Task attachments (files linked to tasks)
- Task activity logs (Task History)

### 🔔 Reminders
- Schedule reminders for tasks
- System tray notifications
- Automatic trigger based on date & time

### 🔁 Habits Management
- Create daily, weekly, and monthly habits
- Check-in system for habits
- Track current streak and best streak
- Habit progress & completion rate
- Activate / deactivate habits
- Archive habits
- View habit history (Habit Logs)

### 📊 Statistics & Insights
- Total tasks, completed tasks, archived tasks
- Task completion rate
- Tasks by priority
- Productivity insights (morning / evening productivity)
- Total habits, active habits, archived habits
- Habit completion rate

### 🏠 Home Dashboard
- Welcome message & date
- Tasks due today
- Habits due today
- Quick overview of productivity
- Personalized productivity insight

- **C# (.NET Framework)**

- **Layered Architecture**
  - Data Access Layer
  - Business Logic Layer
  - Presentation Layer

---

## 🗂️ Database Design

The system uses a relational database with the following main tables:

- People
- Users
- Tasks
- TaskCategories
- TaskLogs
- TaskReminders
- TaskAttachments
- Habits
- HabitLogs

Relationships are designed to ensure data integrity and scalability.
